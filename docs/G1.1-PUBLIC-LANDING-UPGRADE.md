# Genesis G1.1 Public Landing Upgrade

This patch upgrades only the logged-out SalesPilot marketing experience. It does not change authenticated campaign persistence, Business Discovery logic, company discovery, sending, or database migrations.

## Included

- Clear "outbound sales campaign" positioning throughout
- Premium public navigation with Product, How it works, Security and Pricing anchors
- Stronger hero promise and lower-friction "Analyse my website" CTA
- Animated outbound sales campaign workflow preview
- Review, workspace, approval and enterprise-foundation trust signals
- B2B industry proof strip
- Four-step customer journey
- Business understanding, strategy, approval and secure workspace benefits
- Tenant isolation, version history, approval workflow and role access security section
- Honest pricing-positioning section without invented plan prices
- Final conversion CTA and public footer
- Responsive layouts and reduced-motion support

## Verification

Run:

```bash
npm ci
npm run landing:check
npm run auth:boundary-check
npm run auth:draft-check
npm run typecheck
npm run build
```

No migration or new environment variable is required.
