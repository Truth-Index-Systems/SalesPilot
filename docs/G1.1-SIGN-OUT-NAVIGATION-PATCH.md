# Genesis G1.1 — Sign-out Navigation Patch

This patch prevents the sign-in screen from becoming a navigation dead end after sign-out.

## Changes

- The SalesPilot brand on `/sign-in` now links to the overview.
- A visible `Return to SalesPilot` link appears beneath the authentication form.
- Sign-out now uses a stable `/sign-in?next=/` return target.
- Saved campaign discovery drafts are not cleared by sign-out.
- No frozen campaign UI or discovery behaviour was redesigned.
