# Genesis G1.1 — Live Website Analysis Progress

The static blue discovery panel now becomes a live, customer-facing progress experience while website analysis is running.

## Behaviour

- Starts immediately after the user selects **Analyse**.
- Shows a restrained progress percentage and animated progress bar.
- Advances through customer-safe commercial stages:
  - Website reached
  - Reading your website
  - Understanding what you sell
  - Finding your ideal buyers
  - Building your Business DNA
  - Designing outbound sales campaigns
  - Preparing recommendations
- Holds below 100% until the real API response succeeds.
- Shows a short completion state before opening campaign review.
- Reverts to the existing customer-safe error panel if analysis fails.
- Includes a public-information privacy note.
- Supports reduced-motion preferences.

No API schema, Business Discovery logic, frozen proposal UI, authentication behaviour, or database migration was changed.
