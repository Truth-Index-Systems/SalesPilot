# Genesis G1.1 Account Access Patch

This patch fixes the non-responsive account control in the frozen MarketRoute shell.

## Changes

- Replaced the dead `Jaspal` button with an accessible account menu.
- Added direct **Sign in** access from the account menu.
- Added **Settings** access from the account menu.
- Connected **Sign out** to `POST /api/auth/sign-out`.
- Added a persistent **Sign in** link under the sidebar Account section.
- Preserved the existing workspace layout, colours and campaign flow.

## Verification

Run:

```bash
npm ci
npm run typecheck
npm run genesis:check
npm run campaigns:check
npm run build
```
