# Genesis G1.1 — Authentication Flow Persistence Patch

This patch prevents Business Discovery from resetting when a customer must create an account or sign in before launching a campaign.

## Persisted browser state

While a valid analysis exists, MarketRoute continuously stores a versioned 24-hour draft containing:

- validated Business DNA envelope
- canonical website URL
- pages-read context
- selected proposal ID
- exact wizard step
- campaign launch idempotency key

The draft uses local storage so it survives navigation to authentication pages, refreshes, and email-confirmation tabs in the same browser. The previous session-storage draft format is migrated automatically.

## Resume behaviour

After immediate signup or password sign-in, the user returns to the validated `next` path, normally `/campaigns/new`. The wizard restores the exact saved state without rerunning website analysis.

When email confirmation is enabled, the Supabase confirmation redirect now preserves the same validated `next` path. After confirmation and sign-in, the saved campaign state is restored.

## Clearing

The draft and launch idempotency key are removed only after campaign launch succeeds. Failed authentication or campaign launch leaves the approved strategy available for retry.

No database migration is required for this patch.
