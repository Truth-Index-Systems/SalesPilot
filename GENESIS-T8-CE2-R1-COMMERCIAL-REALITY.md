## Lifecycle law
- `ELIMINATED` -> `RESOLVED`.
- Same identity + changed canonical mathematical state -> `CHANGING`.
- `UNRESOLVED` with no prior changed state -> `EMERGING`.
- `SURVIVES` with no changed canonical state -> `ESTABLISHED`.

The lifecycle is not yet the future executive opportunity state machine. It describes the mathematical Commercial Reality only.
