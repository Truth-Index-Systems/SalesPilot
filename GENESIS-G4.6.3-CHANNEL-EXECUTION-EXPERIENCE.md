# Genesis G4.6.3 — Channel Execution Experience

This release turns approved channel-native content into explicit real-world actions.

- Email remains controlled exclusively by the automatic send queue.
- LinkedIn can copy the prepared message and open the verified profile.
- Website forms can copy the message and open the detected form/company website.
- Phone, referral, procurement and relationship routes expose assisted execution actions.
- Non-email engagements can be marked complete or reopened.
- Every execution action is tenant-scoped and recorded in an immutable execution history.

Apply `supabase/migrations/0050_genesis_g463_channel_execution_experience.sql`, then run `npm run genesis:g463-check` and `npm run build`.
