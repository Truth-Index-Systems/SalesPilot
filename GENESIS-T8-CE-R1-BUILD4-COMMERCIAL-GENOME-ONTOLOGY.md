# Genesis T8 CE-R1 Build 4 — Commercial Genome Ontology

## Mission

Define the first canonical, application-independent commercial vocabulary that can inhabit the Genesis T8 9D Commercial Token Graph.

## Boundaries

This build adds no research prompts, no database migration, no Business Fit mathematics, no contact/route logic, and no production pipeline changes. TI-2.1.8 remains frozen and exclusively owns truth qualification.

## Canonical predicate contract

Every predicate has a stable machine ID, human label, objective meaning, token kind, canonical value type, intrinsic mutability, semantic refresh class, evidence expectation, and one or more 9D projections including Truth.

The ontology deliberately excludes fit, attractiveness, priority, recommendations and opportunity scores. These are derived reasoning outputs and belong to later deterministic Commercial Engine mathematics.

## AI / TI responsibility boundary

AI may discover evidence and propose values for canonical predicates. AI does not decide whether those assertions are true.

TI-2.1.8 qualifies the assertion's probability, confidence, coverage, dependency and contradiction state before the token can become authoritative knowledge.

Evidence expectations in the ontology are research guidance only. They never override TI mathematics.

## Versioning law

Existing predicate IDs may not be repurposed. New commercial concepts extend the catalogue under a new ontology version. Breaking semantic changes require explicit version migration.

## Release status

Build 4 defines the v1 ontology contract. Build 5 will test genome completeness and adversarial representability before the ontology is frozen.
