# Genesis T8 — Founder Command Centre Pass 1

## Status
UI / observability release only. Genesis T8 / CIE v1 architecture remains frozen.

## Objective
Turn the founder dashboard into a read-only operating cockpit for autonomous Genesis. The UI exposes persisted Truth, CIE authority and G8 operational state without recalculating commercial decisions.

## Added
- Autonomous Genesis mission status and latest activity.
- Research Density and Truth Health headline metrics.
- Commercial Reality and CIE reachability.
- Governed AI spend / daily ceiling.
- Today throughput: companies, contacts, routes, evidence, Truth snapshots and completed research jobs.
- Expansion and depth queue health, including failures today.
- 10-industry research map using existing G8.2 target/coverage telemetry.
- Highest-value active CIE research directives.
- Recent persisted Genesis entities.
- Constitutional system health surface.
- Deepest-researched company table and founder human-review workspace retained.

## Constitutional boundary
No new commercial score or decision equation was introduced. In particular, the proposed aggregate “Commercial Intelligence Score” is deliberately deferred because architecture is frozen. The command centre displays authoritative source metrics directly.

## Database
No migration required. This release reads existing CIE R4/R6/R7, Truth v2, G8.2 expansion/depth, capacity and operations data.
