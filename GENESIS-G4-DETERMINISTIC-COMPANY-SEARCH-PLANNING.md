# Genesis G4 deterministic Company Discovery planning

Company Discovery planning is now a deterministic local phase.

- PREPARING loads approved campaign and Business DNA.
- PLANNING builds a bounded market-search specification without AI or network access.
- SEARCHING is the first phase permitted to call OpenAI or public web research.
- A provider, JSON or web-search failure can no longer be labelled as a preparation failure.
- No SQL migration is required.
